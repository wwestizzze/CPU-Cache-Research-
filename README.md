CPU Cache Research

Research Topic
Impact of Memory Access Patterns and CPU Cache Hierarchy (L1/L2/L3) on Program Execution Latency.

Project Description
This project investigates how different memory access patterns affect program execution latency.

The experiment compares:
1) Sequential Memory Access
2) Strided Memory Access
3) Random Memory Access

The benchmark was implemented in C++ and measures execution time for different data sizes.

 Files
1) `cache_experiment.cpp` — C++ source code of the experiment.
2) CSV files — experimental measurement results.
3) Research Paper — explanation of the methodology, results, and conclusions.
4) Charts — visual representation of the experimental results.

 Experimental Environment
 The experiment was conducted on a computer with an AMD Ryzen 7 260 processor.

 Purpose
The purpose of this research is to examine the relationship between memory access patterns, CPU cache hierarchy, and program execution latency.
